## 0. TL;DR — 滤波器配置总览

ICM‑45606 的滤波链分为三类，分布在陀螺（Gyro）、加速度（Accel）和温度（Temp）三路信号通路中：

| 滤波环节 | 作用 | 关键寄存器位域 | 所在寄存器 |
|---|---|---|---|
| **UI 低通滤波器 (UI LPF)** | 陀螺 / 加速度 UI 输出通路的可编程截止带宽低通 | `GYRO_UI_LPFBW_SEL`、`GYRO_LPF_BYP` | IPREG_SYS1_REG_172 (0xAC) |
| | | `ACCEL_UI_LPFBW_SEL`、`ACCEL_LPF_BYP` | IPREG_SYS2_REG_131 (0x83) |
| **FIR 抗混叠滤波器 + 插值器 (FIR AAF / Interpolator)** | 信号通路抗混叠与速率转换 | `GYRO_SRC_CTRL` | IPREG_SYS1_REG_166 (0xA6) |
| | | `ACCEL_SRC_CTRL` | IPREG_SYS2_REG_123 (0x7B) |
| **低功耗模式均值滤波器 (LP Averaging Filter)** | 低功耗 (LP) 模式下对样本做平均 | `GYRO_LP_AVG_SEL` | IPREG_SYS1_REG_170 (0xAA) |
| | | `ACCEL_LP_AVG_SEL` | IPREG_SYS2_REG_129 (0x81) |
| **温度低通 + 抽取 (Temp LPF / Decimation)** | 温度传感器低通带宽与处理 ODR | `TMP_LPF_CFG`、`TMP_DEC_CFG` | IPREG_SYS2_REG_128 (0x80) |
| **输出数据率 ODR（滤波带宽基准）** | UI LPF 的截止频率 = ODR/N，必须先设 ODR | `GYRO_ODR`、`ACCEL_ODR` | GYRO_CONFIG0 (0x1C) / ACCEL_CONFIG0 (0x1B) |

> ⚠️ **关键提醒**：除 `*_CONFIG0`、`IREG_*` 这几个寄存器是直接寻址外，**所有滤波寄存器都位于间接访问用户 Bank（IPREG_SYS1 / IPREG_SYS2），不能直接用 7 位地址读写**，必须通过 IREG 间接访问机制操作。详见 [§3](#3-间接访问寄存器-ireg-的读写流程必须先掌握)。

## 1. 信号通路与滤波器架构（背景）

**原数据手册位置**：§4.7 / §4.8（第 40 页）；系统框图 §4.5（第 39 页，Figure 9）。

陀螺 / 加速度信号通路为：
MEMS 传感元 → 放大 / 解调 / 模拟滤波 → 16‑bit ADC → **数字滤波链（FIR AAF + 插值器 → UI LPF）** → UI 数据寄存器 / FIFO。

原文（§4.7, p40）：
> "The resulting signal is amplified, demodulated, and filtered to produce a voltage ... digitized using on‑chip ADCs ..."

数据手册明确指出：**当 FIR AAF 使能时，信号通路带宽由"FIR AAF 与 UI LPF 共同决定"**，并要求参考应用笔记 **AN‑000365（ICM‑456xx User Guide）**（见原数据手册第 261、265 页的 Note）。

## 2. 滤波器配置寄存器一览（含地址 / 复位值 / 原文位置）

### 2.1 直接寻址寄存器（Direct，7‑bit 地址，可直接 R/W）

| 寄存器名 | Addr (Hex/Dec) | 复位值 | 与滤波的关系 | 原文位置 |
|---|---|---|---|---|
| `ACCEL_CONFIG0` | **0x1B / 27** | 0x06 | `ACCEL_ODR[3:0]`：加速度 ODR，决定 UI LPF 截止基准 | §16.26, **p86** |
| `GYRO_CONFIG0` | **0x1C / 28** | 0x06 | `GYRO_ODR[3:0]`：陀螺 ODR，决定 UI LPF 截止基准 | §16.27, **p87** |
| `IREG_ADDR_15_8` | **0x7C / 124** | 0xA2 | 间接地址高 8 位 [15:8] | §16.60, **p111** |
| `IREG_ADDR_7_0` | **0x7D / 125** | 0x38 | 间接地址低 8 位 [7:0] | §16.61, **p111** |
| `IREG_DATA` | **0x7E / 126** | 0x00 | 间接访问数据读 / 写口 | §16.62, **p111** |

**ODR 取值表**（`GYRO_ODR` / `ACCEL_ODR`，§16.26 / §16.27, p86–87；陀螺与加速度编码相同）：

| 编码 (bit3:0) | ODR |
|---|---|
| 0011 | 6.4 kHz（LN） |
| 0100 | 3.2 kHz（LN） |
| 0101 | 1.6 kHz（LN） |
| 0110 | 800 Hz（LN） |
| 0111 | 400 Hz（LP/LN） |
| 1000 | 200 Hz（LP/LN） |
| 1001 | 100 Hz（LP/LN） |
| 1010 | 50 Hz（LP/LN） |
| 1011 | 25 Hz（LP/LN） |
| 1100 | 12.5 Hz（LP/LN） |
| 1101 / 1110 / 1111 | 6.25 / 3.125 / 1.5625 Hz（仅 LP） |

### 2.2 IPREG_SYS1（陀螺滤波相关，间接访问，**基址 = 0xA400**）

寄存器映射总览原文：**§15.7（p74）**；逐位描述原文：**§22（p259–261）**。

#### (1) IPREG_SYS1_REG_166 — `GYRO_SRC_CTRL`（陀螺 FIR AAF + 插值器）
- **地址**：0xA6（Dec 166），间接 16 位地址 = **0xA400 + 0xA6 = 0xA4A6**
- **复位值**：**0x1B**（即 `GYRO_SRC_CTRL[6:5] = 00` → 插值器与 FIR 均 **关闭**）
- **位域**（§22.7, **p260**）：

| 位 | 名称 | 取值与含义 |
|---|---|---|
| 7 | Reserved | — |
| **6:5** | **GYRO_SRC_CTRL** | 0 = 插值器与 FIR 均 **关**；1 = 插值器关、**FIR 开**；2 = 插值器与 FIR **均开**；3 = Reserved(debug) |
| 4:0 | Reserved | — |

#### (2) IPREG_SYS1_REG_170 — `GYRO_LP_AVG_SEL`（陀螺低功耗模式均值滤波）
- **地址**：0xAA（Dec 170），间接 16 位地址 = **0xA400 + 0xAA = 0xA4AA**
- **复位值**：**0x0A**（即 `GYRO_LP_AVG_SEL[4:1] = 0101 = 8x`）
- **位域**（§22.8, **p261**）：

| 位 | 名称 | 取值与含义（低功耗模式平均次数） |
|---|---|---|
| 7:5 | Reserved | — |
| **4:1** | **GYRO_LP_AVG_SEL** | 0000=1x, 0001=2x, 0010=4x, 0011=5x, 0100=7x, 0101=8x, 0110=10x, 0111=11x, 1000=16x, 1001=18x, 1010=20x, 1011=32x, 1100=64x, 其余 Reserved |
| 0 | Reserved | — |

#### (3) IPREG_SYS1_REG_172 — `GYRO_LPF_BYP` + `GYRO_UI_LPFBW_SEL`（陀螺 UI 低通滤波器）⭐ 核心
- **地址**：0xAC（Dec 172），间接 16 位地址 = **0xA400 + 0xAC = 0xA4AC**
- **复位值**：**0x80**（即 `GYRO_LPF_BYP = 1` → **UI LPF 被旁路**，且 `GYRO_UI_LPFBW_SEL = 000`）
- **位域**（§22.9, **p261**）：

| 位 | 名称 | 取值与含义 |
|---|---|---|
| 7:5 | Reserved | — |
| **4** | **GYRO_LPF_BYP** | 0 = UI 通路 LPF **不旁路**（正常滤波）；1 = UI 通路 LPF **旁路**（所有轴） |
| 3 | Reserved | — |
| **2:0** | **GYRO_UI_LPFBW_SEL** | 选择陀螺 UI LPF 截止带宽：<br>000 = Bypass<br>001 = **ODR/4**<br>010 = **ODR/8**<br>011 = **ODR/16**<br>100 = **ODR/32**<br>101 = **ODR/64**<br>110 = **ODR/128**<br>111 = ODR/128 |

> 注（原文 p261）：FIR AAF 使能时，通路带宽由 FIR AAF 与 UI LPF 共同决定，详见 AN‑000365。

## 3. 间接访问寄存器 (IREG) 的读写流程（必须先掌握）

**原数据手册位置**：§13（**p59–60**）。

IREG（间接寄存器）不能用 7 位地址直接寻址，必须用 **16 位内部地址** 经 `IREG_ADDR_15_8 / IREG_ADDR_7_0 / IREG_DATA` 三个直接寄存器访问。

### 3.1 16 位地址 = 基址 + Bank 内偏移

| 目标 Bank | 基址 (Base) | 本文档涉及的滤波寄存器 |
|---|---|---|
| IPREG_SYS1 | **0xA400** | REG_166 / REG_170 / REG_172 |
| IPREG_SYS2 | **0xA500** | REG_123 / REG_128 / REG_129 / REG_131 |

→ 例如访问陀螺 UI LPF 寄存器 (0xAC)：16 位地址 = `0xA400 + 0xAC = 0xA4AC`，即 `IREG_ADDR_15_8 = 0xA4`、`IREG_ADDR_7_0 = 0xAC`。

### 3.2 通用规则（§13.2, p59）
1. 访问 IREG **不支持 burst‑read / burst‑write**。
2. 读 IREG 基于 **read‑pre‑fetch**（见下）。
3. 两次连续 IREG 访问之间需 **最小 4 µs 间隔**（§13.3, p59）。

### 3.3 IREG 写流程（§13.4, p59–60）
1. 在 `IREG_ADDR_7_0 (0x7D)` 与 `IREG_ADDR_15_8 (0x7C)` 写入目标 16 位地址（**Base + Offset**）。
2. 在 `IREG_DATA (0x7E)` 写入待写数据。
3. 上述步骤 **必须在一次 burst‑write 中完成**（避免触发非预期的 read‑prefetch）。
4. 写入 `IREG_DATA` 后硬件自动把数据搬到目标寄存器，并把 16 位地址 **自增**。
5. 等 ≥ 4 µs 后可继续写下一个 `IREG_DATA`（即写入自增后的地址），或重新写入新地址。

### 3.4 IREG 读流程（§13.5, p60）
1. 在 `IREG_ADDR_7_0 / IREG_ADDR_15_8` 写入目标 16 位地址。
2. 拉高 CSB（SPI）或 STOP（I2C）后，硬件触发 **read‑prefetch**，把目标数据取回 `IREG_DATA`。
3. 等 ≥ 4 µs 后读 `IREG_DATA (0x7E)` 得到数据。
4. 读出后地址自增并自动 prefetch 下一个地址。

## 4. 典型配置示例（伪代码）

> 目标：陀螺 / 加速度均 ODR = 1.6 kHz、UI LPF 截止 = ODR/8（即 200 Hz），不旁路；FIR AAF 关闭（默认）。

```c
// 1) 设 ODR（直接寄存器）—— 滤波带宽的基准
//    GYRO_CONFIG0 (0x1C): GYRO_UI_FS_SEL=0010(±1000dps)<<4 | GYRO_ODR=0101(1.6kHz) => 0x25
reg_write(0x1C, 0x25);
//    ACCEL_CONFIG0 (0x1B): ACCEL_UI_FS_SEL=0100(±2g)? 注意字段是 bits[6:4], ACCEL_ODR=0101 => 见 §16.26
reg_write(0x1B, 0x45);

// 2) 陀螺 UI LPF: REG_172 (0xAC), 16-bit addr = 0xA4AC
//    想要 GYRO_LPF_BYP=0(不旁路) | GYRO_UI_LPFBW_SEL=010(ODR/8) => 0x02
ireg_write(0xA4, 0xAC, 0x02);   // base 0xA400 (SYS1) + offset 0xAC

// 3) 加速度 UI LPF: REG_131 (0x83), 16-bit addr = 0xA583
//    ACCEL_LPF_BYP=0(不旁路,bit5=0) | ACCEL_UI_LPFBW_SEL=010(ODR/8) => 0x02
ireg_write(0xA5, 0x83, 0x02);   // base 0xA500 (SYS2) + offset 0x83

// ---- ireg_write 实现（参考 §13.3 / §13.4）----
// 单次 burst-write: 0x7C=addr_hi, 0x7D=addr_lo, 0x7E=data，完成后等 ≥4us
void ireg_write(uint8_t addr_hi, uint8_t addr_lo, uint8_t data) {
    uint8_t buf[3] = { addr_hi, addr_lo, data };
    burst_write(0x7C, buf, 3);          // 0x7C->IREG_ADDR_15_8, 0x7D->IREG_ADDR_7_0, 0x7E->IREG_DATA
    delay_us(4);                         // §13.3 最小间隔
}
```

> 复位默认态提醒：陀螺 UI LPF 默认 **被旁路**（REG_172=0x80），若要使用 UI LPF 必须清 `GYRO_LPF_BYP` 并写入 `GYRO_UI_LPFBW_SEL`。
