# 红外回充发送与接收解析

## 1.发送的形式

4个灯，通过控制不同路的pwm控制强弱信号（pwm都是38khz）。光的强弱主要取决与该路pwm电路上的电阻的大小，电阻小的一路为强光。

### 信号定义：

信号0：发射0.7ms载波 + 2.8ms静默 → 接收端获0.7ms低电平 + 2.8ms高电平

信号1：发射2.8ms载波 + 0.7ms静默 → 接收端获2.8ms低电平 + 0.7ms高电平

### 控制时序：

以0.7ms为一拍，一个槽5拍（3.5ms），一帧8个槽（28ms)，近场帧远场帧间隔28ms，近场帧远场帧各28ms，一帧内只会有全部是近场帧和全部是远场帧的情况，静默间隔196ms。完整周期（280ms).

### 信号与对应数据

| 发射灯序号 | 信号远近 | 对应数据 |
| --- | --- | --- |
| 左灯 | 近 | 0x80 |
|  | 远 | 0x08 |
| 左中灯 | 近 | 0x40 |
|  | 远 | 0x04 |
| 右中灯 | 近 | 0x20 |
|  | 远 | 0x02 |
| 右灯 | 近 | 0x10 |
|  | 远 | 0x01 |

## 2.接收的形式

主要时依靠外部的双边沿中断以及对应经过的时间来进行解码。（基础是红外接收器件会解析载波，最后输出给mcu的只有高低电平）

具体流程：

1.  每次边沿来临时进行判断，如果是上升沿（即当前读到的电平位未高），说明之前是低电平。将当前电平的高低状态以及持续时间传给解码函数
    
2.  解码函数：当高电平足够长时，进入解码状态，对解码结构体进行初始化。然后根据高低电平状态给对应的高低电平持续时间进行更改。然后将其喂给单bit解码函数（one\_bit\_decode（））。
    
3.  one\_bit\_decode内根据电平持续时间判断是超时，还未够一个bit，够持续时间（根据低电平的持续时间判断是1还是0），根据接收的是第几个bit判断是否收满一个字节。判断出是0或1都会重新清掉高低电平持续时间，来接收下一个bit，并把这个bit或到最终的输出字节中。收满字节在将解出的bit或到最终的输出字节外，还会标记正常解出的字节数，这个是用来判断成功率的。
    
4.  数据更新就是将获取的最终的输出字节赋给全局结构体，然后soc包再从全局结构体中copy。数据300ms内不更新就会被清除。整路都没有更新就整路清除，单路没有更新就对应的单路清除（每个单路都有自己上次解算成功的时间戳）。所以若是一段时间没有接收到某一灯的状态，它就会被清除，也就确保了解算出来的数据都是真实的，最新的位置状态。
