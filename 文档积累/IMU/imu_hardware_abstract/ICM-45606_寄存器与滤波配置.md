## 0. TL;DR — 寄存器配置速查

### 0.1 C 结构体风格配置（参考你的 `imu_xxx_config` 写法）

```c
.reg_SOFTRESET            = 0x7F,   /* REG_MISC2: SOFT_RST = bit1（手册 DS-000587 §16.63） */
.value_SOFTRESET_CONFIG   = 0x02,   /* bit1=1 触发软复位（自清）；bit0 是 IREG_DONE，勿用 */
.reg_WHO_AM_I             = 0x72,   /* WHO_AM_I */
.value_WHO_AM_I           = 0x84,   /* ICM-45606 芯片固有 ID */
.reg_PWR_MGMT0            = 0x10,   /* PWR_MGMT0 */
.value_PWR_GYRO_LOWNOISE  = 0x0C,   /* GYRO_MODE[3:2]=11 --> Low-Noise */
.value_PWR_ACCEL_LOWNOISE = 0x03,   /* ACCEL_MODE[1:0]=11 --> Low-Noise */
.reg_GYRO_CONFIG0         = 0x1C,   /* GYRO_CONFIG0 */
.value_GYRO_FS_SEL        = 0x30,   /* GYRO_UI_FS_SEL[7:4]=0011 --> ±500dps */
.value_GYRO_ODR           = 0x06,   /* GYRO_ODR[3:0]=0110 --> 800Hz */
.reg_ACCEL_CONFIG0        = 0x1B,   /* ACCEL_CONFIG0 */
.value_ACCEL_ODR          = 0x16,   /* ACCEL_UI_FS_SEL[6:4]=001(±16g) | ACCEL_ODR=0110(800Hz) */
.reg_RAW_DATA             = 0x00,   /* ACCEL_DATA_X1（数据区起点） */
```

> ✅ **软复位值更正**：手册中 `REG_MISC2(0x7F)` 的 **SOFT_RST 在 bit1**（写 **0x02** 触发，自清；bit0 为 IREG_DONE）。此前注释里的 "bit0 / 0x01" 写的是 IREG_DONE，不会触发复位——已按手册改为 **0x02**（你已在代码中改正）。

### 0.2 地址 / 复位值 / 原文位置速查

| 寄存器 | Addr (Hex/Dec) | 复位值 | 用途 | 原文位置 |
|---|---|---|---|---|
| `REG_MISC2` | **0x7F / 127** | 0x01 | bit1 `SOFT_RST` 软复位；bit0 `IREG_DONE` | §16.63 **p112** |
| `WHO_AM_I` | **0x72 / 114** | 0x84 | 芯片 ID 校验 | §16 **p110**（映射表 §15 p74） |
| `PWR_MGMT0` | **0x10 / 16** | 0x00 | GYRO_MODE[3:2] / ACCEL_MODE[1:0] | §16.17 **p78** |
| `GYRO_CONFIG0` | **0x1C / 28** | 0x06 | GYRO_UI_FS_SEL[7:4] + GYRO_ODR[3:0] | §16.27 **p87** |
| `ACCEL_CONFIG0` | **0x1B / 27** | 0x06 | ACCEL_UI_FS_SEL[6:4] + ACCEL_ODR[3:0] | §16.26 **p86** |
| `ACCEL_DATA_X1`（RAW 起点） | **0x00 / 0** | 0x80 | 加速度 X 高字节（突发读起点） | §16 **p75** |
| `IREG_ADDR_15_8 / 7_0 / IREG_DATA` | **0x7C / 0x7D / 0x7E** | 0xA2/0x38/0x00 | 间接访问滤波寄存器用 | §16.60–62 **p111** |

> 注：参考代码注释曾把 `0x00` 标为 "ACCEL_DATA_X0"，按手册 `0x00` 实为 **ACCEL_DATA_X1（高字节）**，即数据区起点；地址 0x00 作为突发读起点正确。

## 1. 寄存器地址与取值含义

### 1.1 SOFTRESET — `REG_MISC2` (0x7F)  bit1

**原文**：§16.63 **p112**（寄存器映射表 §p63 亦列 `SOFT_RST`/`IREG_DONE`）。

| 位 | 名称 | 取值与含义 |
|---|---|---|
| 7:2 | — | Reserved |
| **1** | **SOFT_RST** | 0=未触发；**1=触发软复位**（写入的 1 完成后**自清为 0**） |
| 0 | IREG_DONE | 0=间接访问进行中；1=间接访问已完成（复位值 0x01 即此位=1） |

> 软复位触发值 = `1<<1` = **0x02**。复位值 0x01 表示上电时 IREG_DONE=1（无访问进行中）。

### 1.2 WHO_AM_I (0x72) = 0x84

8 位设备 ID，出厂值 **0x84**，用于上电后校验通信与芯片型号。

### 1.3 PWR_MGMT0 (0x10) — 复位值 0x00（§16.17 p78）

| 位 | 名称 | 取值与含义 |
|---|---|---|
| 7:4 | — | Reserved |
| **3:2** | **GYRO_MODE** | 00=关；01=Standby；10=Low‑Power (LP)；**11=Low‑Noise (LN)** |
| **1:0** | **ACCEL_MODE** | 00=关；01=关；10=Low‑Power (LP)；**11=Low‑Noise (LN)** |

- `value_PWR_GYRO_LOWNOISE = 0x0C`；`value_PWR_ACCEL_LOWNOISE = 0x03`；合并 = **0x0F**。

### 1.4 GYRO_CONFIG0 (0x1C) — 复位值 0x06（§16.27 p87）

| 位 | 名称 | 取值与含义 |
|---|---|---|
| **7:4** | **GYRO_UI_FS_SEL** | 0001=±2000dps；0010=±1000dps；**0011=±500dps**；0100=±250dps；0101=±125dps；0110=±62.5dps；0111=±31.25dps；1000=±15.625dps |
| **3:0** | **GYRO_ODR** | 0011=6.4k；0100=3.2k；0101=1.6k；**0110=800Hz**；0111=400；1000=200；1001=100；1010=50；1011=25；1100=12.5；1101=6.25；1110=3.125；1111=1.5625 Hz |

- `value_GYRO_FS_SEL = 0x30`（±500dps，bits[7:4]=0011）；`value_GYRO_ODR = 0x06`（800Hz）；合并 GYRO_CONFIG0 = **0x36**。

### 1.5 ACCEL_CONFIG0 (0x1B) — 复位值 0x06（§16.26 p86）

| 位 | 名称 | 取值与含义 |
|---|---|---|
| 7 | — | Reserved |
| **6:4** | **ACCEL_UI_FS_SEL** | **001=±16g**；010=±8g；011=±4g；100=±2g |
| **3:0** | **ACCEL_ODR** | 编码同 GYRO_ODR |

- `value_ACCEL_ODR = 0x16`（= ACCEL_UI_FS_SEL=001(±16g)→0x10 | ACCEL_ODR=0110(800Hz)→0x06）；合并 ACCEL_CONFIG0 = **0x16**。

### 1.6 RAW_DATA 数据区 — 起点 `ACCEL_DATA_X1` (0x00)

突发读从 **0x00** 起，顺序为 ACCEL(X1,X0,Y1,Y0,Z1,Z0) → TEMP → GYRO(X1…Z0) → 时间戳等（高字节在前，与 InvenSense 惯例一致）。

## 2. 滤波器配置（摘要 · 详见 `ICM-45606_滤波器配置说明.md`）

ICM‑45606 的滤波寄存器**不在直接寻址区**，而位于**间接访问用户 Bank**（IPREG_SYS1 = 陀螺；IPREG_SYS2 = 加速度/温度），必须通过 `IREG_ADDR_15_8/IREG_ADDR_7_0/IREG_DATA`（0x7C/0x7D/0x7E）以 **16 位地址**访问。

### 2.1 滤波环节一览

| 滤波环节 | 关键位域 | 间接 16 位地址 | 复位值 | 原文 |
|---|---|---|---|---|
| 陀螺 **UI 低通** | `GYRO_LPF_BYP`(bit4)、`GYRO_UI_LPFBW_SEL`(bits2:0) | IPREG_SYS1_REG_172 = **0xA4AC** | 0x80（默认旁路） | §22.9 p261 |
| 加速度 **UI 低通** | `ACCEL_LPF_BYP`(bit5)、`ACCEL_UI_LPFBW_SEL`(bits2:0) | IPREG_SYS2_REG_131 = **0xA583** | 0x00 | §23.10 p265 |
| 陀螺 **FIR AAF / 插值器** | `GYRO_SRC_CTRL`(bits6:5) | IPREG_SYS1_REG_166 = **0xA4A6** | 0x1B（默认关） | §22.7 p260 |
| 加速度 **FIR AAF / 插值器** | `ACCEL_SRC_CTRL`(bits1:0) | IPREG_SYS2_REG_123 = **0xA57B** | 0x14（默认关） | §23.7 p263 |
| 陀螺 **LP 均值** | `GYRO_LP_AVG_SEL`(bits4:1) | IPREG_SYS1_REG_170 = **0xA4AA** | 0x0A | §22.8 p261 |
| 加速度 **LP 均值** | `ACCEL_LP_AVG_SEL`(bits3:0) | IPREG_SYS2_REG_129 = **0xA581** | 0x02 | §23.9 p265 |
| 温度 **LPF / 抽取** | `TMP_LPF_CFG`(bits2:0)、`TMP_DEC_CFG`(bits5:3) | IPREG_SYS2_REG_128 = **0xA580** | 0x00 | §23.8 p264 |

### 2.2 UI 低通截止频率编码（`*_UI_LPFBW_SEL`）

`000`=Bypass；`001`=ODR/4；`010`=ODR/8；`011`=ODR/16；`100`=ODR/32；`101`=ODR/64；`110`=ODR/128；`111`=ODR/128。

> 截止频率 = **ODR / N**，故须先配好 ODR（GYRO_CONFIG0/ACCEL_CONFIG0）。例：ODR=800Hz、选 `010`(ODR/8) ⇒ 截止 ≈100Hz。
> ⚠️ 陀螺 UI LPF **默认被旁路**（REG_172=0x80）；若要使用须清 `GYRO_LPF_BYP` 并写入 `GYRO_UI_LPFBW_SEL`。

### 2.3 间接访问（IREG）写流程要点（§13 p59–60）

1. `IREG_ADDR_7_0(0x7D)`、`IREG_ADDR_15_8(0x7C)` 写入目标 16 位地址（Base+offset）。
2. `IREG_DATA(0x7E)` 写入数据。
3. 三步**必须在一次 burst-write 中完成**；写完后硬件自动搬运并地址自增。
4. 两次 IREG 访问间需 **≥4µs** 间隔；**不支持 burst read/write**。

## 3. 典型初始化序列（伪代码）

```c
/* 1) 软复位（bit1=0x02，自清） */
BspImu_WriteOneByte(0x7F, 0x02);       /* REG_MISC2: SOFT_RST */
HwSys_Delay1ms(12);

/* 2) 使能陀螺/加速度 Low-Noise */
BspImu_WriteOneByte(0x10, 0x0C | 0x03); /* PWR_MGMT0: GYRO_MODE=LN | ACCEL_MODE=LN */
HwSys_Delay1ms(1);

/* 3) 量程 + ODR */
BspImu_WriteOneByte(0x1C, 0x30 | 0x06); /* GYRO_CONFIG0 : ±500dps | 800Hz */
HwSys_Delay1ms(1);
BspImu_WriteOneByte(0x1B, 0x16);        /* ACCEL_CONFIG0: ±16g | 800Hz */
HwSys_Delay1ms(2);

/* 4) UI 低通（间接访问；例：陀螺/加速度 ODR/8 ≈100Hz，不旁路） */
ireg_write(0xA4, 0xAC, 0x02);           /* GYRO  UI LPF: GYRO_LPF_BYP=0 | BW=010(ODR/8) */
ireg_write(0xA5, 0x83, 0x02);           /* ACCEL UI LPF: ACCEL_LPF_BYP=0 | BW=010(ODR/8) */

/* ireg_write(addr_hi, addr_lo, data): burst-write 0x7C/0x7D/0x7E，完成后 ≥4us */
```
