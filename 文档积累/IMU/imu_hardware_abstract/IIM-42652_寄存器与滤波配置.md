# IIM‑42652 寄存器与滤波器配置说明

> 数据手册来源：**TDK InvenSense IIM‑42652 Datasheet**（Document Number: **DS‑000401**, Revision 1.0，共 111 页）
> 文件名：`IIM-42652.pdf`
>
> 本文档摘取该手册中与"初始化寄存器 + 滤波器配置"直接相关的内容：**寄存器地址、复位值、位域、取值含义**，并在每处标注原 PDF 的**章节 / 页码**便于回查。
>
> ✅ **关于"40607"滤波代码**：你提供的示例里标注为"40607"的滤波写入（`0x51 / 0x53 / 0x52`，值 `0x04 / 0x08 / 0x66`）经逐条核对，**与 IIM‑42652 手册完全吻合**（`GYRO_CONFIG1=0x51`、`GYRO_ACCEL_CONFIG0=0x52`、`ACCEL_CONFIG1=0x53`），"40607"为 **IIM‑42652 的笔误**。下文 §2.2 直接对该套代码逐位解码。

## 0. TL;DR — 寄存器配置速查

### 0.1 C 结构体风格配置

```c
.reg_SOFTRESET            = 0x11,   /* DEVICE_CONFIG: SOFT_RESET_CONFIG = bit0 */
.value_SOFTRESET_CONFIG   = 0x01,   /* bit0=1 触发软复位（写后需等 ≥1ms） */
.reg_WHO_AM_I             = 0x75,   /* WHO_AM_I */
.value_WHO_AM_I           = 0x6F,   /* IIM-42652 芯片固有 ID */
.reg_PWR_MGMT0            = 0x4E,   /* PWR_MGMT0 */
.value_PWR_GYRO_LOWNOISE  = 0x0C,   /* GYRO_MODE[3:2]=11 --> Low-Noise */
.value_PWR_ACCEL_LOWNOISE = 0x03,   /* ACCEL_MODE[1:0]=11 --> Low-Noise */
.reg_GYRO_CONFIG0         = 0x4F,   /* GYRO_CONFIG0 */
.value_GYRO_FS_SEL        = 0x40,   /* GYRO_FS_SEL[7:5]=010 --> ±500dps */
.value_GYRO_ODR           = 0x06,   /* GYRO_ODR[3:0]=0110 --> 1kHz（本芯片无 800Hz 档） */
.reg_ACCEL_CONFIG0        = 0x50,   /* ACCEL_CONFIG0 */
.value_ACCEL_ODR          = 0x06,   /* ACCEL_FS_SEL[7:5]=000(±16g) | ACCEL_ODR=0110(1kHz) */
.reg_RAW_DATA             = 0x1F,   /* ACCEL_DATA_X1（数据区起点；含温度则从 0x1D 起） */
/* —— UI 低通滤波器（即原"40607"滤波代码） —— */
.reg_GYRO_CONFIG1         = 0x51,   /* 含 TEMP_FILT_BW / GYRO_UI_FILT_ORD / GYRO_DEC2_M2_ORD */
.value_FILT_GYRO_CONFIG1  = 0x04,
.reg_GYRO_ACCEL_CONFIG0   = 0x52,   /* 含 ACCEL_UI_FILT_BW[7:4] / GYRO_UI_FILT_BW[3:0] */
.value_FILT_GA_CONFIG0    = 0x66,
.reg_ACCEL_CONFIG1        = 0x53,   /* 含 ACCEL_UI_FILT_ORD / ACCEL_DEC2_M2_ORD */
.value_FILT_ACCEL_CONFIG1 = 0x08,
```

### 0.2 地址 / 复位值 / 原文位置速查

| 寄存器 | Addr (Hex/Dec) | 复位值 | 用途 | 原文位置 |
|---|---|---|---|---|
| `DEVICE_CONFIG` | **0x11 / 17** | 0x00 | bit0 `SOFT_RESET_CONFIG` 软复位；bit4 SPI_MODE | §p61 |
| `WHO_AM_I` | **0x75 / 117** | 0x6F | 芯片 ID 校验 | §p84 |
| `PWR_MGMT0` | **0x4E / 78** | 0x00 | TEMP_DIS / IDLE / GYRO_MODE / ACCEL_MODE | §p72 |
| `GYRO_CONFIG0` | **0x4F / 79** | 0x06 | GYRO_FS_SEL[7:5] + GYRO_ODR[3:0] | §p73 |
| `ACCEL_CONFIG0` | **0x50 / 80** | 0x06 | ACCEL_FS_SEL[7:5] + ACCEL_ODR[3:0] | §p74 |
| `GYRO_CONFIG1` | **0x51 / 81** | 0x16 | TEMP_FILT_BW[7:5] + GYRO_UI_FILT_ORD[3:2] + GYRO_DEC2_M2_ORD[1:0] | §p75 |
| `GYRO_ACCEL_CONFIG0` | **0x52 / 82** | 0x11 | ACCEL_UI_FILT_BW[7:4] + GYRO_UI_FILT_BW[3:0] ⭐ | §p76 |
| `ACCEL_CONFIG1` | **0x53 / 83** | 0x0D | ACCEL_UI_FILT_ORD[4:3] + ACCEL_DEC2_M2_ORD[2:1] | §p77 |
| `ACCEL_DATA_X1`（RAW 起点） | **0x1F / 31** | 0x80 | 加速度 X 高字节（突发读起点） | §p63 |

> 📌 该芯片寄存器分 **Bank 0 / 1 / 2 / 4**（§13 p57）。上述 0x11~0x53、0x75 均为 **Bank 0** 直接寻址。可编程 AAF / Notch 在 Bank 1/2（见 §2.3，需经 `REG_BANK_SEL`(0x76) 切换）。

## 1. 寄存器地址与取值含义

### 1.1 SOFTRESET — `DEVICE_CONFIG` (0x11)  bit0

**原文**：§p61。

| 位 | 名称 | 取值与含义 |
|---|---|---|
| 7:5 | — | Reserved |
| 4 | SPI_MODE | 0=SPI Mode0/3（默认）；1=Mode1/2 |
| 3:1 | — | Reserved |
| **0** | **SOFT_RESET_CONFIG** | 0=Normal（默认）；**1=触发软复位**。写 1 后**需等 ≥1ms** 再访问其它寄存器 |

> 软复位触发值 = **0x01**。

### 1.2 WHO_AM_I (0x75) = 0x6F

**原文**：§p84。8 位设备 ID，出厂值 **0x6F**。

### 1.3 PWR_MGMT0 (0x4E) — 复位值 0x00（§p72）

| 位 | 名称 | 取值与含义 |
|---|---|---|
| 7:6 | — | Reserved |
| 5 | TEMP_DIS | 0=温度传感器使能（默认）；1=关闭 |
| 4 | IDLE | 1=即使 Accel/Gyro 关闭也保持 RCOSC 上电 |
| **3:2** | **GYRO_MODE** | 00=关；01=Standby；10=Reserved；**11=Low‑Noise (LN)** |
| **1:0** | **ACCEL_MODE** | 00=关；01=关；10=Low‑Power (LP)；**11=Low‑Noise (LN)** |

- `value_PWR_GYRO_LOWNOISE  = 0x0C`；`value_PWR_ACCEL_LOWNOISE = 0x03`；合并 = **0x0F**。
- 从 OFF 切换后 **200µs 内不要写寄存器**；Gyro 上电后保持 ≥45ms。

### 1.4 GYRO_CONFIG0 (0x4F) — 复位值 0x06（§p73）

| 位 | 名称 | 取值与含义 |
|---|---|---|
| **7:5** | **GYRO_FS_SEL** | 000=±2000dps；001=±1000dps；**010=±500dps**；011=±250dps；100=±125dps；101=±62.5dps；110=±31.25dps；111=±15.625dps |
| 4 | — | Reserved |
| **3:0** | **GYRO_ODR** | 见下表 |

GYRO_ODR 编码（§p73）：0001=32k, 0010=16k, 0011=8k, 0100=4k, 0101=2k, **0110=1kHz(默认)**, 0111=200Hz, 1000=100Hz, 1001=50Hz, 1010=25Hz, 1011=12.5Hz, 1111=500Hz。

> ⚠️ **IIM‑42652 没有 800Hz 档**（1kHz 之后直接到 200Hz）。参考代码里的 800Hz 仅适用于 ICM‑45606 / ICM‑42607；本芯片用 **1kHz (0x06)** 作为最接近档。

- `value_GYRO_FS_SEL = 0x40`（±500dps）；`value_GYRO_ODR = 0x06`（1kHz）；合并 GYRO_CONFIG0 = **0x46**。

### 1.5 ACCEL_CONFIG0 (0x50) — 复位值 0x06（§p74）

| 位 | 名称 | 取值与含义 |
|---|---|---|
| **7:5** | **ACCEL_FS_SEL** | **000=±16g**；001=±8g；010=±4g；011=±2g |
| 4 | — | Reserved |
| **3:0** | **ACCEL_ODR** | 同 GYRO_ODR，并增加 LP 档：1100=6.25 / 1101=3.125 / 1110=1.5625 Hz |

- `value_ACCEL_ODR = 0x06`（= ACCEL_FS_SEL=000(±16g) | ACCEL_ODR=0110(1kHz)）；合并 ACCEL_CONFIG0 = **0x06**。

### 1.6 RAW_DATA 数据区 — 起点 `ACCEL_DATA_X1` (0x1F)

**原文**：§p62–64。突发读顺序（地址递增，均为 SYNCR 同步寄存器）：

| Addr | 寄存器 | | Addr | 寄存器 |
|---|---|---|---|---|
| 0x1D | TEMP_DATA1 | | 0x24 | ACCEL_DATA_Z0 |
| 0x1E | TEMP_DATA0 | | 0x25 | GYRO_DATA_X1 |
| **0x1F** | **ACCEL_DATA_X1** | | 0x26 | GYRO_DATA_X0 |
| 0x20 | ACCEL_DATA_X0 | | 0x27 | GYRO_DATA_Y1 |
| 0x21 | ACCEL_DATA_Y1 | | 0x28 | GYRO_DATA_Y0 |
| 0x22 | ACCEL_DATA_Y0 | | 0x29 | GYRO_DATA_Z1 |
| 0x23 | ACCEL_DATA_Z1 | | 0x2A | GYRO_DATA_Z0 |

> 仅读加速度+陀螺（12 字节）从 **0x1F** 起；含温度（14 字节）从 **0x1D** 起。

## 2. 滤波器配置

IIM‑42652 的滤波链比 ICM‑42607‑C 更丰富：**AAF（可编程 2 阶，Bank1/2）→ 可选 Notch → DEC2 + UI 低通（0x51/0x52/0x53）**。其中 **UI 低通是用户最常配置的部分，且正是你现有代码所设置的**。

### 2.1 GYRO_CONFIG1 (0x51) — 复位 0x16（§p75）

| 位 | 名称 | 取值与含义 |
|---|---|---|
| **7:5** | **TEMP_FILT_BW** | 温度 DLPF：000=4000Hz(近旁路,默认)；001=170Hz；010=82Hz；011=40Hz；100=20Hz；101=10Hz；110/111=5Hz |
| 4 | — | Reserved |
| **3:2** | **GYRO_UI_FILT_ORD** | 陀螺 UI 滤波器阶数：00=1阶；**01=2阶**；10=3阶；11=Reserved |
| **1:0** | **GYRO_DEC2_M2_ORD** | 陀螺 DEC2_M2 滤波器阶数：00=Reserved；01=Reserved；**10=3阶**；11=Reserved |

### 2.2 GYRO_ACCEL_CONFIG0 (0x52) — 复位 0x11 ⭐ UI 低通带宽核心（§p76）

| 位 | 名称 | 取值与含义（LN 模式，BW 相对 ODR） |
|---|---|---|
| **7:4** | **ACCEL_UI_FILT_BW** | 0=ODR/2；1=max(400Hz,ODR)/4(默认)；2=/5；3=/8；4=/10；5=/16；**6=/20**；7=/40；14/15=Low‑Latency |
| **3:0** | **GYRO_UI_FILT_BW** | 编码同上 |

### 2.3 ACCEL_CONFIG1 (0x53) — 复位 0x0D（§p77）

| 位 | 名称 | 取值与含义 |
|---|---|---|
| 7:5 | — | Reserved |
| **4:3** | **ACCEL_UI_FILT_ORD** | 加速度 UI 滤波器阶数：00=1阶；**01=2阶**；10=3阶；11=Reserved |
| **2:1** | **ACCEL_DEC2_M2_ORD** | 加速度 DEC2_M2 阶数：00/01=Reserved；**10=3阶**；11=Reserved |
| 0 | — | Reserved |

### 2.4 对你现有"40607"滤波代码的逐位解码

```c
BspImu_WriteOneByte(0x51, 0x04);   /* GYRO_CONFIG1        */
BspImu_WriteOneByte(0x53, 0x08);   /* ACCEL_CONFIG1       */
BspImu_WriteOneByte(0x52, 0x66);   /* GYRO_ACCEL_CONFIG0  */
```

| 写入 | 寄存器 (0x__ ) | 解码结果 |
|---|---|---|
| `0x51 = 0x04` | GYRO_CONFIG1 | `0x04 = 0000_0100` ⇒ TEMP_FILT_BW=**000(4000Hz, 近旁路)**；GYRO_UI_FILT_ORD=**01(2阶)**；GYRO_DEC2_M2_ORD=00 |
| `0x53 = 0x08` | ACCEL_CONFIG1 | `0x08 = 0000_1000` ⇒ ACCEL_UI_FILT_ORD=**01(2阶)**；ACCEL_DEC2_M2_ORD=00 |
| `0x52 = 0x66` | GYRO_ACCEL_CONFIG0 | `0x66 = 0110_0110` ⇒ ACCEL_UI_FILT_BW=**6**、GYRO_UI_FILT_BW=**6**（均为 `max(400Hz,ODR)/20`） |

**效果汇总**：陀螺/加速度均为 **2 阶 UI 低通**，带宽 code=6。当 ODR=1kHz 时，`BW = max(400,1000)/20 = 50Hz`；温度滤波近旁路（4000Hz）。

> ⚠️ **小提示**：`GYRO_DEC2_M2_ORD=00` 与 `ACCEL_DEC2_M2_ORD=00` 按手册属 Reserved（仅 10=3阶 有效）。若 DEC2 滤波器未启用一般无影响；如需启用 DEC2，应改为 `10`（即 0x51/0x53 相应位置 1）。是否需要调整请你定夺。

### 2.5 可编程 AAF 与 Notch（进阶，Bank 1/2，现有代码使用默认值）

IIM‑42607‑C 的 AAF 是固定的，而 **IIM‑42652 的 AAF 是用户可编程的 2 阶低通**，并可旁路；另有 Notch 陷波器。需经 `REG_BANK_SEL (0x76)` 切到 Bank 1/2 后访问（§Anti‑Alias Filter **p26**、§Notch and AAF Operation **p55**、寄存器描述 **p85**）。

| 滤波器 | 寄存器（Bank / Addr） | 关键位 | 复位值 |
|---|---|---|---|
| GYRO AAF 使能 | Bank1 / 0x0C | `GYRO_AAF_DIS`(bit1)、`GYRO_AAF_DELT`(bits5:0) | 0xA0 |
| GYRO AAF 参数 | Bank1 / 0x0D、0x0E | `GYRO_AAF_DELTSQR`、`GYRO_AAF_BITSHIFT` | 0x80 / — |
| ACCEL AAF 使能 | Bank2 / 0x03 | `ACCEL_AAF_DIS`(bit0)、`ACCEL_AAF_DELT`(bits6:1) | — |
| ACCEL AAF 参数 | Bank2 / 0x04、0x05 | `ACCEL_AAF_DELTSQR`、`ACCEL_AAF_BITSHIFT` | — / 0x62 |

> 带宽 → DELT/DELTSQR/BITSHIFT 的映射表见手册 §p26（"Anti‑Alias Filter"）。你现有初始化代码**未改动 AAF**，即使用上述复位默认值。

## 3. 典型初始化序列（伪代码，含你现有的滤波写入）

```c
/* 1) 软复位 */
BspImu_WriteOneByte(0x11, 0x01);       /* DEVICE_CONFIG: SOFT_RESET_CONFIG */
HwSys_Delay1ms(2);                      /* 手册要求写后 ≥1ms */

/* 2) 使能陀螺/加速度 Low-Noise */
BspImu_WriteOneByte(0x4E, 0x0C | 0x03); /* PWR_MGMT0: GYRO_MODE=LN | ACCEL_MODE=LN */
HwSys_Delay1ms(1);

/* 3) 量程 + ODR（注意：本芯片无 800Hz，用 1kHz） */
BspImu_WriteOneByte(0x4F, 0x40 | 0x06); /* GYRO_CONFIG0 : ±500dps | 1kHz */
HwSys_Delay1ms(1);
BspImu_WriteOneByte(0x50, 0x06);        /* ACCEL_CONFIG0: ±16g | 1kHz */
HwSys_Delay1ms(2);

/* 4) UI 低通滤波器（即原"40607"滤波代码，此处为 IIM-42652） */
BspImu_WriteOneByte(0x51, 0x04);        /* GYRO_CONFIG1: TEMP~bypass, GYRO_UI 2阶 */
HwSys_Delay1ms(2);
BspImu_WriteOneByte(0x53, 0x08);        /* ACCEL_CONFIG1: ACCEL_UI 2阶 */
HwSys_Delay1ms(2);
BspImu_WriteOneByte(0x52, 0x66);        /* GYRO_ACCEL_CONFIG0: GYRO/ACCEL_UI_FILT_BW=6 */
HwSys_Delay1ms(2);
```
