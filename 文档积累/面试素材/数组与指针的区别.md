# 数组与指针的区别

1.数据实体不同

数组里面的数据就是数据实体，比如int，char这些

指针的实体是一个地址，所以指针是一个存放地址的变量。



2.位置固定的区别

数组是一块固定的内存块，指针是可以任意更改地址的，比如刚开始指向a的地址，后面就可以改为指向b的地址



3.内存大小的区别

数据内存大小是数组内所有变量加起来，比如一个大小为5的int数组，它的大小就是4*5=20B

指针的大小一般就是4B，32位单片机中。



4.存储位置（内存区域）——决定实时性

- 数组：空间在编译时就确定了。如果定义在函数内（局部数组），分配在栈（Stack）上；如果定义在全局/静态区，分配在静态存储区。分配时间固定（零开销）。
- 指针：指针变量本身在栈或静态区，但它指向的数据可以来自任何地方（栈、静态区、堆`malloc`）。如果指向堆，`malloc`的耗时是不确定的（有抖动），这是硬实时系统的大忌。
- *实战意义*：FreeRTOS创建任务时，`pxStack` 既可以用 `malloc` 动态分配（不推荐），也可以用预先定义的静态数组 `static StackType_t ucStack[128];`（硬实时推荐）。静态创建任务栈使用。



嵌入式中的一个场景就是，rtos任务创建栈时的方式

主要有两种创建方式：

- **方式A：动态创建（`xTaskCreate`）—— 用的是“指针”指向堆内存**
  - 你调用 `xTaskCreate(..., &pxCreatedTask)` 时，内核内部会调用 `pvPortMalloc()` 从**堆（Heap）**里挖出一块内存作为栈。
  - 内核拿到的只是一个**内存地址（指针）**，这块内存没有数组名。
  - **致命缺点（硬实时大忌）**：`pvPortMalloc` 的耗时**不确定**（首次调用可能涉及内存块合并），且频繁创建/删除任务会导致**内存碎片**。在航空航天或汽车电子（AUTOSAR）中，这通常是明令禁止的。
- **方式B：静态创建（`xTaskCreateStatic`）—— 用的是“数组”**
  - 你需要提前定义一个静态数组：`static StackType_t uxTaskBuffer[ 256 ];`
  - 然后调用 `xTaskCreateStatic(..., uxTaskBuffer, &pxTCB);`，把这个**数组（退化为指针）**传给内核作为任务栈。
  - **核心优势**：这块内存是**编译时**确定的，分配耗时**零抖动（Zero Jitter）**，且绝不会产生碎片。

------

### 针对“动态创建”这个场景，嵌入式铁律如下：

| 你的需求                                                     | 推荐做法                                      | 使用的实体                                                   |
| :----------------------------------------------------------- | :-------------------------------------------- | :----------------------------------------------------------- |
| **系统启动时创建的核心任务**（如电机控制、CAN通信）          | **静态创建** `xTaskCreateStatic`              | 底层用**数组**（预分配），把数组首地址传给API（此时数组退化为指针）。 |
| **运行过程中临时创建的辅助任务**（如OTA升级时的HTTP下载任务，完成后即删除） | 如果必须做，只能用 **动态创建** `xTaskCreate` | 底层用 **堆指针**（`pvPortMalloc`返回的地址）。但**千万注意**：创建完后必须用指针操作，且任务删除后要手动释放。 |
| **任务的句柄（Handle）**                                     | 无论哪种方式                                  | 永远用 **指针变量** 接收返回值（`TaskHandle_t xHandle = NULL;`）。 |

------

### 为什么你可能会误解“动态创建就是用指针”？

因为你在调用 `xTaskCreate` 时，传入的参数和返回的值确实全是**指针**。但请记住：**指针只是一个“中介”**。

- 如果你传给内核的**数组名**（静态方式），指针指向的是**编译时确定的栈区**。
- 如果你不传参（动态方式），指针指向的是**运行时从堆里挖出来的内存**。

**终极实战结论（背下来）：**

> **“凡是需要保证实时性和稳定性的任务，永远不要用 `xTaskCreate`（动态指针），一律使用 `xTaskCreateStatic` + 提前定义的全局静态数组。只有在调试阶段或极其不重要的非实时日志打印任务中，才考虑用动态创建（指针）。”**

如果你现在正要在项目里创建一个任务，可以告诉我这个任务是做什么的（比如是处理串口命令，还是执行PID闭环），我帮你判断这个任务配不配“拥有一个静态数组栈”。😊





5. 赋值与修改（左值与右值）

- 数组：数组名是常量地址（右值），不能被赋值。你不能写 `array = another_array;`，因为数组名没有对应的独立存储空间来存放新地址，它就是个“地标”。
- 指针：指针是变量（左值），可以随时指向新的地址。你可以写 `ptr = &new_var;`。
