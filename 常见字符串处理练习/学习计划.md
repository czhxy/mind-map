## 一、为什么嵌入式要专门练字符串

嵌入式里字符串处理有三个绕不开的现实：

| 现实 | 后果 |
|---|---|
| **RAM 小、没有 MMU** | 越界写直接踩坏别的变量或栈，不报错、只跑飞（HardFault） |
| **不确定输入长度** | 串口/网络来的数据长度不可控，`strcpy`/`sprintf` 是溢出重灾区 |
| **中断 + 主循环并发** | 库函数里 `strtok` 这类用静态变量的函数不可重入，会串数据 |

所以练的重点不是"会调用"，而是**知道这个函数的契约、失效条件、以及有没有更安全的替代**。

## 三、每道题的「四步练习法」

1. **裸写**：不看答案，写出实现和函数原型。5 分钟没思路就跳过，先做后面的。
2. **补边界**：强制自己列 3 组边界输入再动手：
   - 空串 `""` / `NULL`
   - 没有结尾符 / 越界长度
   - 源和目标是同一块内存（重叠）
3. **对答案**：展开 `<details>` 逐行对比。重点看三处差异——**返回值类型**、**指针推进方式**、**循环终止条件**。
4. **记坑**：把踩到的坑补进本文档第六节的速查表。

## 四、环境准备

Windows 下用 MinGW 的 gcc（Git Bash 里可直接用）：

```bash
# ★ 推荐的标准命令，注意 -D__USE_MINGW_ANSI_STDIO=1（原因见下）
gcc -Wall -Wextra -std=c11 -g -D__USE_MINGW_ANSI_STDIO=1 本文件.c -o 程序 && ./程序.exe

# 更严格：把警告当错误，逼自己处理返回值
gcc -Wall -Wextra -Werror -std=c11 -g -D__USE_MINGW_ANSI_STDIO=1 本文件.c -o 程序

# 若 gcc 支持（WSL / MSYS2 通常支持），开启内存检查抓越界
gcc -Wall -Wextra -std=c11 -g -fsanitize=address,undefined 本文件.c -o 程序 && ./程序
```

**强烈建议始终加 `-Wall -Wextra`**。像 `char c = getchar(); if (c == 0xFF)` 这种永远为假的 bug，编译器会直接告诉你。

### ★ 为什么必须加 `-D__USE_MINGW_ANSI_STDIO=1`

MinGW-w64 默认链接微软的 MSVCRT，而 **MSVCRT 的 `snprintf` 不符合 C99**：

```c
char b[4];
int n = snprintf(b, 4, "%s", "0.005");   /* 太长，会被截断 */
```

| 实现 | 返回值 `n` | 缓冲区内容 |
|---|---|---|
| C99 标准（Linux / MSYS2 / 加宏后） | **5**（本该写入的长度） | `"0.0"` + `'\0'` |
| MSVCRT 默认 | **-1**（只表示出错） | `"0.00"`，**可能没有 `'\0'`** |

这个差异会让第 21、22 题的答案在 Windows 上跑出错误结果，而且实战里会引入真实 bug：

- `n == -1` 时你**无法区分"格式化出错"和"只是被截断"**，也就无法正确上报截断；
- 截断后缓冲区甚至可能不是合法字符串，后面 `printf("%s")` 直接越界读。

加上 `-D__USE_MINGW_ANSI_STDIO=1` 后，MinGW 会改用自己实现的符合标准的 `snprintf`。

> 实测环境：`gcc 8.1.0 (x86_64-win32-seh-rev0, MinGW-W64)`，`-std=c11` 与 `-std=gnu11` 均如此。

## 六、常见坑速查表

做题过程中持续补充。

| # | 坑 | 现象 | 正确做法 |
|---|---|---|---|
| 1 | `strlen` 返回 `size_t`（无符号） | `if (strlen(a) - strlen(b) > 0)` 恒为真 | 直接比大小 `strlen(a) > strlen(b)`，或先转 `int` |
| 2 | `strncpy` 在 `src` 长度 ≥ `n` 时**不补** `'\0'` | 目标串后续 `printf("%s")` 越界读 | 手动 `dst[n-1] = '\0'`，或用 `strlcpy` |
| 3 | `strncat` 需要 `strlen(dst)+n+1` 的空间 | 按 `n` 申请缓冲导致溢出 | 它最多加 `n` 字符**再加**一个 `'\0'` |
| 4 | 数组做参数退化成指针 | `void f(char b[])` 里 `sizeof(b) == 4/8` | 长度必须额外传参 |
| 5 | 字符串字面量在只读段 | `char *p = "abc"; p[0] = 'A';` 崩 | 要改就写 `char p[] = "abc";` |
| 6 | `strcpy` 源目标重叠 | 结果不确定 | 用 `memmove` |
| 7 | `strtok` 改原串且用静态变量 | 中断/多任务里数据串扰、原串被破坏 | 用 `strtok_r`，或先拷一份 |
| 8 | `snprintf` 返回值 ≥ size 表示**被截断** | 当成成功，日志/报文被悄悄截断 | 判断 `ret < 0 \|\| (size_t)ret >= size` |
| 9 | `char` 是否带符号由实现决定 | `char c; if (c >= 0x80)` 在 ARM 上恒假 | 处理字节一律用 `unsigned char` / `uint8_t` |
| 10 | `atoi` 无法报错 | 非法输入静默返回 0，和真值 0 混淆 | 用 `strtol` + `endptr` 判断 |
| 11 | `%s` 打印无终止符的缓冲 | 越界读到栈上垃圾 | 保证 `'\0'`，或限制宽度 `%.*s` |
| 12 | Cortex-M0/M3 无硬件除法 | `itoa` 里 `% 10` 很慢 | 转 10 进制可用减法/查表优化 |
| 13 | `memcpy` 不是按位拷贝 | 用它做 `(float)` 类型转换，违反严格别名 | 用 `union` 或 `memcpy` 到同类型变量（合法） |
| 14 | 缓冲区长度按字节算，中文字符占 3 字节 | 按"字数"分配缓冲区 | 一律按字节，必要时用 `strnlen` 限界 |
| 15 | MinGW 默认的 `snprintf` 截断时返回 `-1` | 无法区分"截断"和"出错"；缓冲可能无 `'\0'` | 编译加 `-D__USE_MINGW_ANSI_STDIO=1` |

## 附录：通用测试脚手架

每题都用 `gcc 单文件` 编译，所以不引入测试框架，直接用 `assert` + 计数宏。
复制到每题文件顶部即可（`练习题.md` 里各题的测试代码已经内置）。

```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>
#include <stdint.h>
#include <ctype.h>
#include <limits.h>
#include <assert.h>

static int g_pass = 0, g_fail = 0;

#define CHECK(cond)                                                     \
    do {                                                                \
        if (cond) {                                                     \
            g_pass++;                                                   \
        } else {                                                        \
            g_fail++;                                                   \
            printf("  [FAIL] %s:%d  %s\n", __FILE__, __LINE__, #cond);  \
        }                                                               \
    } while (0)

#define REPORT() printf("== pass=%d fail=%d ==\n", g_pass, g_fail)

/* 用来看"字符串里到底有什么"，\r\n 和不可见字符一目了然
 * 故意不加 static：未使用的 static 函数会触发 -Wall 的 -Wunused-function 警告 */
void dump_hex(const uint8_t *p, size_t n)
{
    for (size_t i = 0; i < n; i++) {
        printf("%02X ", p[i]);
    }
    printf("\n");
}
```

> 注意：`dump` 若没用到会报 `-Wunused-function`。不想看警告就把它删掉，或者临时加一句
> `if (0) { dump(NULL, 0); }`。
