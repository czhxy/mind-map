# ICM‑42607‑C 寄存器与滤波器配置说明

> 数据手册来源：**InvenSense ICM‑42607‑C Datasheet**（Document Number: **DS‑000398**, Revision 1.0，共 100 页）
> 文件名：`301180057_陀螺仪IC_INVENSENSE_ICM-42607-C(2).pdf`
>
> 本文档摘取该手册中与"初始化寄存器 + 滤波器配置"直接相关的内容：**寄存器地址、复位值、位域、取值含义**，并在每处标注原 PDF 的**章节 / 页码**便于回查。
>
> ⚠️ **关于"40607"滤波代码**：你提供的示例里标注为"40607"的滤波写入（`0x51 / 0x53 / 0x52`）经核对**并非 ICM‑42607‑C** 的滤波寄存器——在 ICM‑42607‑C 手册中 `0x51/0x52/0x53` 是 **OFFSET_USER3/4/5（用户偏置校准寄存器，§p89）**，与滤波无关。那套地址实际对应的是 **IIM‑42652**（见 `IIM-42652_寄存器与滤波配置.md`，已确认"40607"为笔误）。ICM‑42607‑C 的真实 UI 滤波器在 **0x22 / 0x23 / 0x24**（见 §2）。

## 0. TL;DR — 寄存器配置速查

### 0.1 C 结构体风格配置（参考你的 `imu_xxx_config` 写法）

```c
.reg_SOFTRESET            = 0x02,   /* SIGNAL_PATH_RESET: SOFT_RESET_DEVICE_CONFIG = bit4 */
.value_SOFTRESET_CONFIG   = 0x10,   /* bit4=1 触发软复位（硬件自清） */
.reg_WHO_AM_I             = 0x75,   /* WHO_AM_I */
.value_WHO_AM_I           = 0x61,   /* ICM-42607-C 芯片固有 ID */
.reg_PWR_MGMT0            = 0x1F,   /* PWR_MGMT0 */
.value_PWR_GYRO_LOWNOISE  = 0x0C,   /* GYRO_MODE[3:2]=11 --> Low-Noise */
.value_PWR_ACCEL_LOWNOISE = 0x03,   /* ACCEL_MODE[1:0]=11 --> Low-Noise */
.reg_GYRO_CONFIG0         = 0x20,   /* GYRO_CONFIG0 */
.value_GYRO_FS_SEL        = 0x40,   /* GYRO_UI_FS_SEL[6:5]=10 --> ±500dps */
.value_GYRO_ODR           = 0x06,   /* GYRO_ODR[3:0]=0110 --> 800Hz */
.reg_ACCEL_CONFIG0        = 0x21,   /* ACCEL_CONFIG0 */
.value_ACCEL_ODR          = 0x06,   /* ACCEL_UI_FS_SEL[6:5]=00(±16g) | ACCEL_ODR=0110(800Hz) */
.reg_RAW_DATA             = 0x0B,   /* ACCEL_DATA_X1（数据区起点；含温度则从 0x09 起） */
```

## 1. 寄存器地址与取值含义

### 1.1 SOFTRESET — `SIGNAL_PATH_RESET` (0x02)  bit4

**原文**：§Register Map p39；位域描述 §p44。

| 位 | 名称 | 取值与含义 |
|---|---|---|
| 7:5 | — | Reserved |
| **4** | **SOFT_RESET_DEVICE_CONFIG** | 0 = 不复位（默认）；**1 = 触发软件复位**（硬件自清，auto‑clear） |
| 3 | — | Reserved |
| 2 | FIFO_FLUSH | 1 = 清空 FIFO（需按特定时序：写1→等1.5µs→读回应为0） |
| 1:0 | — | Reserved |

> 软复位触发值 = `1<<4` = **0x10**。复位完成后该位自动清零；手册另有 `RESET_DONE` 状态位可查询。参考现有驱动延时约 12ms（保守值）。

### 1.2 WHO_AM_I (0x75) = 0x61

**原文**：§p67。8 位设备 ID，复位/出厂值 **0x61**，用于上电后校验通信与芯片型号。

### 1.3 PWR_MGMT0 (0x1F) — 复位值 0x00

**原文**：§p53。

| 位 | 名称 | 取值与含义 |
|---|---|---|
| 7 | ACCEL_LP_CLK_SEL | 0 = ACCEL LP 模式用 WUOSC（最低功耗，推荐）；1 = 用 RCOSC |
| 6:5 | — | Reserved |
| 4 | IDLE | 1 = 即使 Accel/Gyro 关闭也保持 RCOSC 上电 |
| **3:2** | **GYRO_MODE** | 00=关；01=Standby；10=Reserved；**11=Low‑Noise (LN)** |
| **1:0** | **ACCEL_MODE** | 00=关；01=关；10=Low‑Power (LP)；**11=Low‑Noise (LN)** |

- `value_PWR_GYRO_LOWNOISE  = 0x0C`（bits[3:2]=11）
- `value_PWR_ACCEL_LOWNOISE = 0x03`（bits[1:0]=11）
- 合并写入 = `0x0C | 0x03 = 0x0F`
- ⚠️ 从 OFF 切换到其它模式后，**200µs 内不要写任何寄存器**；Gyro 上电后需保持 ≥45ms。

### 1.4 GYRO_CONFIG0 (0x20) — 复位值 0x06

**原文**：§p54。

| 位 | 名称 | 取值与含义 |
|---|---|---|
| 7 | — | Reserved |
| **6:5** | **GYRO_UI_FS_SEL** | 00=±2000dps；01=±1000dps；**10=±500dps**；11=±250dps |
| 4 | — | Reserved |
| **3:0** | **GYRO_ODR** | 见下表 |

GYRO_ODR 编码（§p54）：

| bit3:0 | ODR | | bit3:0 | ODR |
|---|---|---|---|---|
| 0101 | 1.6 kHz | | 1001 | 100 Hz |
| **0110** | **800 Hz** | | 1010 | 50 Hz |
| 0111 | 400 Hz | | 1011 | 25 Hz |
| 1000 | 200 Hz | | 1100 | 12.5 Hz |

- `value_GYRO_FS_SEL = 0x40`（±500dps，bits[6:5]=10）
- `value_GYRO_ODR    = 0x06`（800Hz）
- 合并写入 GYRO_CONFIG0 = **0x46**

### 1.5 ACCEL_CONFIG0 (0x21) — 复位值 0x06

**原文**：§p55。

| 位 | 名称 | 取值与含义 |
|---|---|---|
| 7 | — | Reserved |
| **6:5** | **ACCEL_UI_FS_SEL** | **00=±16g**；01=±8g；10=±4g；11=±2g |
| 4 | — | Reserved |
| **3:0** | **ACCEL_ODR** | 编码同 GYRO_ODR，并增加 LP 档：1101=6.25 / 1110=3.125 / 1111=1.5625 Hz |

- `value_ACCEL_ODR = 0x06`（= ACCEL_UI_FS_SEL=00(±16g) | ACCEL_ODR=0110(800Hz)）
- 合并写入 ACCEL_CONFIG0 = **0x06**

### 1.6 RAW_DATA 数据区 — 起点 `ACCEL_DATA_X1` (0x0B)

**原文**：§p48–52。突发读顺序（地址递增）：

| Addr | 寄存器 | | Addr | 寄存器 |
|---|---|---|---|---|
| 0x09 | TEMP_DATA1 | | 0x11 | GYRO_DATA_X1 |
| 0x0A | TEMP_DATA0 | | 0x12 | GYRO_DATA_X0 |
| **0x0B** | **ACCEL_DATA_X1** | | 0x13 | GYRO_DATA_Y1 |
| 0x0C | ACCEL_DATA_X0 | | 0x14 | GYRO_DATA_Y0 |
| 0x0D | ACCEL_DATA_Y1 | | 0x15 | GYRO_DATA_Z1 |
| 0x0E | ACCEL_DATA_Y0 | | 0x16 | GYRO_DATA_Z0 |
| 0x0F | ACCEL_DATA_Z1 | | 0x17 | TMST_FSYNCH |
| 0x10 | ACCEL_DATA_Z0 | | | |

> 仅读加速度+陀螺（12 字节）从 **0x0B** 起；含温度（14 字节）从 **0x09** 起。各轴高字节复位值 0x80，低字节 0x00。

## 2. 滤波器配置

### 2.1 信号通路与 AAF（背景）

**原文**：§Signal Path **p23**。

> "In Low‑Noise Mode, the ADC output is sent through an Anti‑Alias Filter (AAF). **The AAF is a filter with fixed coefficients (not user configurable), also the AAF cannot be bypassed.** The AAF is followed by a 1st Order Low Pass Filter …"

即 ICM‑42607‑C 的 **AAF 固定、不可配置、不可旁路**；用户可调的只有其后的 **UI 低通滤波器 (UI DLPF)** 与温度 DLPF。

### 2.2 用户可配置的滤波寄存器

#### (1) TEMP_CONFIG0 (0x22) — `TEMP_FILT_BW[6:4]`，复位 0x00（§p55–56）

| bit6:4 | TEMP_FILT_BW |
|---|---|
| 000 | DLPF bypassed |
| 001 | 180 Hz |
| 010 | 72 Hz |
| 011 | 34 Hz |
| 100 | 16 Hz |
| 101 | 8 Hz |
| 110 / 111 | 4 Hz |

#### (2) GYRO_CONFIG1 (0x23) — `GYRO_UI_FILT_BW[2:0]`，复位 **0x31**（§p56）

| bit2:0 | GYRO_UI_FILT_BW（陀螺 UI 低通截止） |
|---|---|
| 000 | Low pass filter bypassed |
| 001 | 180 Hz |
| 010 | 121 Hz |
| 011 | 73 Hz |
| **100** | **53 Hz** |
| 101 | 34 Hz |
| 110 | 25 Hz |
| 111 | 16 Hz |

> 复位值 0x31 ⇒ bit[2:0]=001 ⇒ 180Hz（高字节 bit[7:3] 为 reserved，复位为 0b00110）。

#### (3) ACCEL_CONFIG1 (0x24) — 复位 **0x41**（§p56）

| 位 | 名称 | 取值与含义 |
|---|---|---|
| **6:4** | **ACCEL_UI_AVG** | ACCEL LP 模式平均次数：000=2x,001=4x,010=8x,011=16x,100=32x,101/110/111=64x |
| 3 | — | Reserved |
| **2:0** | **ACCEL_UI_FILT_BW** | 编码同 GYRO_UI_FILT_BW（000=bypass … 111=16Hz） |

> 复位值 0x41 ⇒ ACCEL_UI_AVG=100(32x)、ACCEL_UI_FILT_BW=001(180Hz)。

### 2.3 推荐滤波取值（示例：UI 低通 ≈53Hz）

```c
BspImu_WriteOneByte(0x22, 0x20);  /* TEMP_CONFIG0: TEMP_FILT_BW=010 --> 72Hz  */
BspImu_WriteOneByte(0x23, 0x04);  /* GYRO_CONFIG1 : GYRO_UI_FILT_BW=100 --> 53Hz */
BspImu_WriteOneByte(0x24, 0x04);  /* ACCEL_CONFIG1: ACCEL_UI_FILT_BW=100 --> 53Hz (LP avg 维持默认) */
```

> ICM‑42607‑C 的 UI 低通为**固定带宽表**（与 ODR 无关），不像 IIM‑42652 / ICM‑45606 那样按 ODR/N 计算。

## 3. 典型初始化序列（伪代码）

```c
/* 1) 软复位 */
BspImu_WriteOneByte(0x02, 0x10);      /* SIGNAL_PATH_RESET: SOFT_RESET_DEVICE_CONFIG */
HwSys_Delay1ms(12);                    /* 等待复位完成（bit4 自清；保守延时） */

/* 2) 使能陀螺/加速度 Low-Noise */
BspImu_WriteOneByte(0x1F, 0x0C | 0x03); /* PWR_MGMT0: GYRO_MODE=LN | ACCEL_MODE=LN */
HwSys_Delay1ms(1);

/* 3) 量程 + ODR */
BspImu_WriteOneByte(0x20, 0x40 | 0x06); /* GYRO_CONFIG0 : ±500dps | 800Hz */
HwSys_Delay1ms(1);
BspImu_WriteOneByte(0x21, 0x06);        /* ACCEL_CONFIG0: ±16g | 800Hz */
HwSys_Delay1ms(2);

/* 4) UI 低通滤波器（AAF 固定不可配） */
BspImu_WriteOneByte(0x22, 0x20);        /* TEMP  72Hz */
HwSys_Delay1ms(2);
BspImu_WriteOneByte(0x23, 0x04);        /* GYRO  53Hz */
HwSys_Delay1ms(2);
BspImu_WriteOneByte(0x24, 0x04);        /* ACCEL 53Hz */
HwSys_Delay1ms(2);
```
