# 面试自我介绍（嵌入式软件工程师）

面试官您好，我叫陈志豪，是深圳大学电子信息工程专业2027 届应届生，来应聘贵司的嵌入式软件工程师岗位。

以下是我的个人简介。



首先介绍实习相关的部分：

我之前在深圳乐动机器人担任嵌入式开发实习生，参与割草机器人整机项目的开发与维护。工作内容主要有以下几点：

第一是独立负责新项目外设板的开发，主要是驱动开发以及数据传输。驱动开发包括根据数据手册对AHT20 温湿度、MLX90642 红外热成像两路 I2C 设备进行开发，以及将算法板的红外回充解码相关代码移植到外设板上，数据传输部分主要是与应用组的同事在原来项目的数据传输框架下定义新增模块的具体协议。驱动代码经团队评审后合入主分支，支撑了量产验证阶段按期推进。

第二是负责老机器的边缘功能开发，主要包括新imu的适配和静音功能的完善。

第三是处理测试 BUG 与客诉问题单，处理总问题数达30+，嵌入式相关问题80%以上当天闭环，涉及跨组复杂问题会输出嵌入式层面的根因分析，然后移交对应的同事进行下一步的分析。

第四主要是一些突发问题的处理。



然后是项目相关部分：

课外我独立完成了两个项目：一个是基于 STM32 双 MCU 和 CAN 总线的智能中控面板，使用 FreeRTOS 做 8 任务分层，CAN 发送任务配合 peek 机制做到不丢帧、不乱序，同时用 LVGL 实现了仪表盘 UI 和 YMODEM 协议的 OTA 升级；另一个是基于 ESP32 和 FreeRTOS 的双电机 FOC 控制项目，实现了 Clark/Park 变换、SVPWM 调制和三闭环串级 PID，落地了 8 种可配置触觉反馈模式。



最后是我的技术栈：

我熟悉 C 语言、STM32、FreeRTOS 以及 I2C、SPI、UART、CAN 等常见总线，动手能力和根因分析能力比较扎实，希望有机会加入贵公司，谢谢。
