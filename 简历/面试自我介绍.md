## 完整版（推荐）

面试官您好，我叫陈志豪，深圳大学电子信息工程专业，2027 届应届生，应聘嵌入式软件工程师岗位。

我目前正在深圳乐动机器人做嵌入式开发实习生，参与割草机器人整机项目。工作内容主要有以下几点：
1.独立负责新项目外设板的数据透传驱动开发，从数据手册适配了 AHT20 温湿度、MLX90642 红外成像两路 I2C 设备，以及移植充电桩红外 38kHz 载波信号的 GPIO 解码相关代码，并与算法共同制定了含分包机制的透传协议，驱动代码经团队评审后合入主分支，支撑了量产验证阶段按期推进。
2.独立完成了因缺货带来的 IMU 器件移植。主要是通过阅读新imu的数据手册，将其相关配置变成与原imu相同。
3.处理测试 BUG 与客诉问题单，加起来约30-40个，嵌入式相关问题80%以上当天闭环，跨组复杂问题会输出根因分析报告后移交对应团队。bug主要是电机相关。

课外我独立完成了两个项目：一个是基于 STM32 双 MCU 和 CAN 总线的智能中控面板，使用 FreeRTOS 做 8 任务分层，CAN 收发用深度 64 的对称队列解耦，配合 peek 机制做到不丢帧、不乱序，同时用 LVGL 实现了仪表盘 UI 和 YMODEM 协议的 OTA 升级；另一个是基于 ESP32 双核和 FreeRTOS 的双电机 FOC 控制，实现了 Clark/Park 变换、SVPWM 调制和三闭环串级 PID，落地了 8 种可配置触觉反馈模式。

最后熟悉 C 语言、STM32、FreeRTOS 以及 I2C、CAN 等常见总线，动手和根因分析能力比较扎实，希望有机会加入贵公司，谢谢。

## 使用小贴士

- **语音自然、每句之间有停顿**，不要背稿感，45 秒版本念下来大约 50 秒左右即可。
- **按岗位微调重点**：
  - 偏电机控制/算法 → 多强调 FOC 项目（Clark/Park、SVPWM、三闭环 PID、8 种触觉反馈）。
  - 偏量产/底层驱动 → 多强调实习（外设透传协议、IMU 移植、BUG 根因分析闭环）。
  - 偏 UI/应用层 → 多强调中控面板（LVGL、FreeRTOS 任务分层、CAN 队列、OTA）。
- **数据是加分项**：80% 当天闭环、30+ BUG、深度 64 队列、8 种反馈模式、60% 调试效率提升，这些具体数字记得自然带出。
